# Demo video: target 3 minutes 20 seconds

Record the actual application with your screen recorder. Use the English narration below or equivalent English subtitles. Keep the final video between 2 and 5 minutes. This script is preparation, not a finished video.

Before recording: launch from the README, use nonpersonal sample notes, close unrelated windows, enlarge the recording region so text is readable, and keep developer mode off. Arrange a reminder to trigger during the recording: create a note due about three minutes from now with a one-minute reminder, remembering that the time picker uses minute precision. Test the timing once before the final take.
